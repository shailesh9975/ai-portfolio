## 🛠 Tech Stack & Core Competencies

### AI/ML Evaluation & Prompt Engineering

* **LLM Benchmarking & Evaluation:** Evaluation of model outputs across OpenAI, AWS Bedrock, and Snorkel AI platforms.
* **RAG & Prompt Validation:** Systematic evaluation of hallucination rates, contextual accuracy, retrieval quality, and prompt robustness.
* **Domain Testing:** Complex reasoning evaluation, including mathematical reasoning (algebra, calculus, number theory), logic verification, and multi-modal content quality.

### Quality Assurance & Data Annotation

* **API & System Testing:** Postman, REST API validation, edge-case testing, and regression suites.
* **Data & Image Annotation:** CVAT, Labelbox, bounding-box validation, and dataset quality auditing.
* **Issue Tracking & QA Workflows:** JIRA, bug lifecycle management, and test plan creation.

### Engineering & Infrastructure

* **Frontend Framework:** Next.js, React, Tailwind CSS, TypeScript.
* **DevOps & Infrastructure:** Docker, Jenkins, Git, Vercel deployment.

## ⚙️ Getting Started

### Prerequisites

* **Node.js**: v18.0.0 or higher
* **Package Manager**: `pnpm`, `npm`, or `yarn`

### Local Development Setup

1. **Clone the repository:**
```bash
git clone https://github.com/shailesh9975/ai-portfolio.git
cd ai-portfolio

```


2. **Install dependencies:**
```bash
pnpm install

```


3. **Run the local development server:**
```bash
pnpm dev

```


4. **View in browser:**
Open `http://localhost:3000` to preview the site locally.
